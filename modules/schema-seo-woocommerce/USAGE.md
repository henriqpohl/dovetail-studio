# Schema SEO WooCommerce — Usage

Enable **Schema SEO WooCommerce** in **Dovetail Studio → Modules**, then open **Dovetail Studio → Schema SEO WooCommerce**. Map WooCommerce attributes for brand, manufacturer, color, material and size; configure GTIN/MPN meta keys; optionally configure merchant return policy.

## Possible Errors and How to Fix Them

### Product values are missing from schema
Confirm the configured WooCommerce attribute/meta key actually contains data on the product or its parent variable product.
